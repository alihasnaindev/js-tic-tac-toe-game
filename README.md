# 🎮 Tic Tac Toe Game (JavaScript)

An interactive, responsive, and fun **Tic Tac Toe** game built using vanilla **JavaScript**, **HTML5**, and **CSS3**. This project was created as part of my JavaScript learning journey to practice DOM manipulation, event listeners, and game logic.

---

## ✨ Features
- 👥 **2-Player Mode**: Play locally with a friend on the same device.
- 🎯 **Win/Draw Detection**: Automatically checks winning combinations and handles tie games.
- 🔄 **Reset / New Game**: One-click reset button to start a new round instantly.
- 📱 **Responsive Design**: Smooth experience on mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Modern styling & layout (Flexbox/Grid).
- **JavaScript (ES6)**: Game logic and DOM updates.
